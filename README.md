# Skyknight Raven

Oasis Dream — the knight side of the same story as Peachfall.
Meet Sae’s fragments. Do not collect them. Watch the play, or walk it.

**Peachfall (princess) stays at** [forest-mist-zest-civic.grok.me](https://forest-mist-zest-civic.grok.me). This repo is a separate game.

## Play locally

```bash
npm install
npm run dev          # http://0.0.0.0:8080  (dev)
```

## tower.local

See [HOSTING.md](HOSTING.md). `docker compose up --build -d` then http://tower.local:8088

## Controls

WASD or arrows walk · drag / right stick look · Sit · Kneel · Hop · Gaze
